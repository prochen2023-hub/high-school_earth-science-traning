高中一年級｜地科秘笈 v4.13｜第三章名師圖像全面整合版
========================================================

這是從 v4.12 完整網站升級的覆蓋更新包，不是獨立的第三章圖片集。

開啟方法：
1. 解壓縮 ZIP。
2. 直接雙擊根目錄 index.html，或把全部內容覆蓋到 GitHub Desktop 的 Repository 根目錄。
3. Commit to main，再 Push origin。
4. 在 GitHub Code 頁面確認 index.html 寫著 v4.13，且最新 Pages Actions 對應新 commit。
5. 重新開啟網站，必要時 Ctrl+Shift+R。

本版新增：
- 4 張第三章大圖（地球結構、板塊、岩石、臺灣）。
- 六組概念圖學堂，共 21 個可切換的觀察鏡頭。
- 2 張另外製作的判圖 SVG：震源與地震走時；中洋脊海底擴張與古地磁。
- 課程圖卡可放大，逐張有「先看線索／再推原因／一題收束」。
- 岩石組的 6 張實物標本對照（使用者提供教材照片裁切；臺灣地點是類型代表地點，並非每張照片的採集地）。
- 原有臺灣地質圖鑑、海底地形圖、11 種岩石樣本、38 個獨立小圖解、第四章與第二次段考 A/B 卷保留。

重要科學註記：
- 高彩資訊圖、立體剖面、海底擴張圖為教學示意，並非實測斷層面、地質界線或按比例剖面。
- 地函主要仍是固態；臺灣造山屬弧陸碰撞為主的複雜系統，不是單純兩塊大陸碰撞。
- 岩石樣本必須由礦物組成、顆粒、層理與片理等辨認，不單看顏色。
- 本站不隱藏科學限制，實際數值判讀請參照課程內正式圖表、實測資料與官方地質圖。
