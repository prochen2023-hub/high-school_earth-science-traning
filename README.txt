高中一年級｜地科秘笈 v2（完整架構版）

開啟方式
- 直接開啟 index.html 即可。
- 手機、平板、電腦皆可使用。
- 學習進度、星星、段考範圍儲存在瀏覽器 localStorage。

本版完成
1. 正式課本架構：7章、23小節。
2. 每節固定教學流程：生活問題 → 一句先懂 → 因果鏈 → 核心概念 → 高中名詞 → 易錯點 → 3題。
3. 「我真的看不懂」降階救援：從最白話版本慢慢拉回高中語言。
4. 段考範圍控制：
   - 一段預設：第1–2章
   - 二段預設：第3–4章
   - 三段／期末預設：第5–7章
   - 可任意自訂章節
5. 老師進度滑桿：可設定目前教到哪一小節。
6. 今日8分鐘：只從目前段考範圍抽題；可限制只抽已教內容。
7. ABCD四級闖關：全部可預覽，不上鎖。
8. 模擬段考A/B卷：20題、100分，題目範圍跟著段考設定。
9. 每章概念互動：地球歷史尺度、P/S波賽跑、空氣團上升冷卻、潮汐概念、季節公轉、氣候能量平衡、風險概念。
10. 少字模式、中文朗讀、星星與完成度。

內容原則
- 依十二年國教普通型高中自然科學領域地球科學必修學習內容。
- 章節結構參考目前高中地科常見教材七章架構。
- 文字為重新撰寫的生活化教學內容，不複製課本文字。
- 教學主軸：先解碼生活現象，再補正式名詞，最後轉成題目。
