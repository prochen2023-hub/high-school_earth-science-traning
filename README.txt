高中一年級｜地科秘笈 v4.0「完整但不變難」重構版
====================================================

開啟方式
- 解壓縮後直接開啟 index.html。
- GitHub Pages：把 geo_v40 資料夾內 5 個檔案上傳到 repo 根目錄即可。
- 手機／平板／電腦皆採響應式版面。
- 進度、星星、段考範圍存在瀏覽器 localStorage；沿用舊版相同 key，舊進度可延續。

v4.0 為什麼重構
- v3.x 的「動手看」主要綁整章，容易讓不同小節看到同一大包內容。
- v4.0 改成 7章／23小節「每節專屬互動」，內容更均衡。
- 每節固定只走：生活問題 → 一句先懂 → 因果故事 → 三塊概念 → 動手看 → 正式名詞 → 3題 → 教同學一招。
- 深入名詞放在可展開第二層，避免「補完整」反而變難。

全站固定設計
1. 鼓勵語：先不用背、還差一小步、快練成了、你已經能教人。
2. 每節「😎 教同學這一招」：30秒說法＋反問題＋高手一句。
3. 答錯不只顯示錯誤，改成提示回圖找原因。
4. 每完成一節會把高手句解鎖到首頁「高手招式」。
5. 少字模式＋分段中文朗讀。
6. 段考範圍、老師進度、今日8分鐘、ABCD闖關、A/B模擬卷保留。

第2章重點實作
- 2-1：P/S波粒子運動＋地球內部透視。
- 2-2：
  * 中洋脊 → 新洋殼 → 海底擴張 → 老洋殼冷卻增密 → 海溝隱沒 → 地震／火山。
  * 「把海水變透明」海溝剖面，0～-11 km尺度概念。
  * 明確說明：隱沒的是較老、較冷、整體較密的海洋岩石圈，不是因為「海水比較重」。
  * 地磁錄音帶：岩漿冷卻 → 磁性礦物記錄當時地磁 → 地磁倒轉 → 對稱磁條帶。
  * 第二層正式名詞：居里溫度、熱剩磁。
  * 地磁倒轉原因：液態外核導電流體的地磁發電機是複雜動態系統；磁場可重組並反轉，無固定週期，也不能預測下一次何時發生。
  * 全球板塊／地震／隱沒帶概念圖與臺灣位置。
- 2-3：P/S速報賽跑、近震盲區概念、地盤放大。

第5章重點實作
- 5-1 從太空看地球：
  * 可見光／紅外線／假色遙測切換。
  * LEO／MEO／GEO 位置與用途：LEO <約2,000 km；GPS約20,200 km；GEO約35,786 km。
  * 衛星不是「沒有重力」，而是持續自由落體繞行。
  * SpaceX：與 Tesla 為不同公司；用 Falcon 可重複使用與 Starlink 低軌衛星作現代航太案例。
  * 極光：太陽風 → 磁層 → 高層大氣 → 極光橢圓。
- 5-2 從臺灣看天空：
  * 地球自轉 → 日夜／周日運動。
  * 月份＋緯度雙滑桿：四季、太陽高度概念、白晝長短、南北半球相反季節。
  * 極圈內可直接出現永晝／永夜；臺灣緯度會明示不會有真正永晝永夜。
  * 北極星：臺灣約22～25°N，因此北極星約在北方二十多度高；同一鐘點四季切換時，周圍星座換位置而北極星近乎固定。
  * 月球「同步自轉 vs 假設不自轉」對照，破解「月球沒有自轉」迷思。
- 5-3 宇宙：
  * 宇宙地址：地球 → 地月系 → 太陽系 → 銀河系 → 本星系群 → 更大尺度 → 可觀測宇宙。
  * 現行八大行星＋冥王星矮行星，說明「以前九大行星」是分類改變，不是冥王星消失。
  * 行星公轉×自轉雙滑桿，分清「繞太陽」與「自己轉」。
  * 距太陽遠近：距離影響收到的太陽能，但溫度還受大氣、反照率等因素影響，金星作反例。
  * 光年時光機：光年是距離；看得越遠就是看越久以前的光。

其餘章節也都有專屬互動
- 第1章：吸積、分異、海洋／氧氣演化、地層與半衰期。
- 第3章：大氣分層、氣壓、露點、空氣上升、風向、天氣圖、颱風。
- 第4章：溫鹽密度、浪／潮／流、ENSO。
- 第6章：天氣vs氣候、冰雪回饋、海平面、溫室能量、氣候歸因、減緩vs調適。
- 第7章：永續三面向、生命週期、能源多指標取捨。

科學資料核對（2026-11-02）
- NASA Science：太陽系目前正式為八大行星；冥王星為矮行星；太陽系位於銀河系。
- NASA Earth Observatory / NASA 技術資料：LEO/MEO/GEO 軌道高度與用途概念。
- GPS.gov：GPS 約位於20,200 km中地球軌道。
- USGS：海底擴張、玄武岩磁化、正常／反向磁條帶與地磁倒轉紀錄。
- NOAA SWPC：極光橢圓與太陽風／磁層關係。
- SpaceX / Tesla 官方資料：Elon Musk 同時領導相關公司；SpaceX 與 Tesla 為不同公司；SpaceX 的可重複使用火箭與 Starlink 為現代案例。

注意
- 所有太陽系、衛星高度、海溝、板塊、地震速報等視覺均為教學示意；需要壓縮比例時會標示或在文字說明，不應拿圖面距離直接量真實值。
- 地震速報時間為比例化概念估算，不是實際地震預報。
