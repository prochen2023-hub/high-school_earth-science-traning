高中一年級｜地科秘笈 v4.12｜第三、四章圖像互動整合版

一、使用方式
1. 解壓縮全部檔案。單純開啟根目錄 index.html 即可。
2. 第三章：原本六節、臺灣地質圖鑑、海底地形、岩石實物、38 張圖解與闖關均保留。
3. 第四章：首頁或左側選單點「第四章大氣探險」，不必開啟獨立 HTML 檔。
4. 可直接以 index.html#weather 開第四章首頁，index.html#second-exam 開第二次段考選卷。
5. 所有大氣圖像均放在 assets/weather/，主要互動和試題在 weather.js。

二、本版第四章完整教學地圖（依使用者提供課本 p.100–137 範圍）
4-1 大氣的垂直結構
  生活問題：高山空氣為什麼稀薄、為什麼某些大氣層又會增溫？
  圖像：垂直四層主視覺、氣壓—高度曲線、氣溫—高度曲線、逆溫圖。
  互動：高度／氣壓比、各層氣溫和大氣層、正常／逆溫切換。
  知識：1013 hPa、1 mb=1 hPa、760 mmHg、氣壓非線性下降、四層大氣特徵。
4-2 水循環與天氣變化
  生活問題：杯子冒水珠、霧從哪來、山區為何下雨？
  圖像：水循環潛熱、飽和水氣量曲線、成雲四種抬升、焚風山坡剖面。
  互動：溫度＋水氣量→相對濕度、露點、飽和值；成雲方式切換；山高與焚風計算。
  知識：蒸發吸熱、凝結放熱、露點／飽和、凝結核、霧露霜雲雨、冷卻與抬升方式。
4-3 大氣的水平運動
  生活問題：東北風從哪裡來、海風陸風反方向的原因？
  圖像：氣壓梯度力、科氏力、摩擦力、海陸風、季風、高低壓水平環流。
  互動：風場受力三階段、海風陸風切換、冬夏季風、高壓低壓環流。
  知識：北半球偏向、等壓線密度、近地面摩擦、地轉風、輻合／輻散。
4-4 判讀天氣圖
  生活問題：氣象預報員為何能從等壓線和鋒面判斷天氣？
  圖像：測站模式、三位數氣壓編碼、四鋒面符號、連續三日鋒面、溫帶氣旋四階段、月雨量判圖。
  互動：氣壓代碼解碼、鋒面比較、三天天氣圖、溫帶氣旋發展切換。
  知識：測站資料、觀測儀器、冷／暖／滯留／囚錮鋒、H/L、臺灣鋒面與季風。

三、練習與段考
- 第四章各節原創練習 8 題，共 32 題，每題有解析。
- 第二次段考 A / B 各 20 題、各 100 分、40 分鐘；每卷第三章 10 題、第四章 10 題。
- 題型含圖像、數值、情境、判讀等；非逐題複製教科書或既有考古題。
- 舊第三章單章 A/B 練習保留作為複習，不冒稱第二次段考。

四、圖像使用與科學限制
- assets/weather 內四張章節級圖像為重新生成的整合視覺圖，隨 ZIP 本地提供，無外部圖片失效問題。
- 視覺圖卡用於激發興趣；精確座標、物理關係請以網頁內有坐標的操作圖、正式定義及教師用書核對。
- 壓力高度使用 0–30 km 標準大氣近似分段模型，不是每天各地的即時觀測。
- 飽和水氣以水氣密度計算做高中近似；高於 100% 相對濕度的滑桿情境是凝結可能出現的示範，不是穩定的平衡狀態。
- 焚風計算以固定乾/濕絕熱遞減率和飽和起點示意，真實個案另受地形、凝結高度、環流條件影響。
- 天氣圖連續三日與月雨量示範是自編教學案例，並非真實特定日期觀測紀錄。

五、GitHub Desktop 部署（重要）
1. GitHub Desktop > Show in Explorer，確認開啟的是已連接的 repo 根目錄。
2. 將本 ZIP 解壓後的全部檔案複製到 repo 根目錄，選取「取代同名檔案」。
3. 不要上傳外層資料夾，也不要讓 Windows 把 index.html 變成 index (2).html。
4. GitHub Desktop > Changes > Commit to main > Push origin。
5. GitHub > Actions 檢查本次 Commit 對應的 Pages build and deployment 是 Success。
6. 若網站仍顯示舊版，先在 GitHub Code 檢查根目錄 index.html 是否含有 v4.12，再確認 Pages 指向 main/(root)，並用 Ctrl+Shift+R 重載。
