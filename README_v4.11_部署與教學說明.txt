【GitHub Desktop 更新方法（避免舊版停留在 v4.9）】
  1. 下載並解壓到空的新資料夾。
  2. 在 GitHub Desktop 點「Show in Explorer」打開真正的 clone repository 本機資料夾。
  3. 將 ZIP 最上層的檔案和 assets、guides、legacy 等資料夾全部複製到 repo 根目錄；選擇「覆蓋」同名檔。
  4. 特別確認 repo 根目錄只有正確的 index.html（不能變成 index (2).html 或把整個資料夾再包一層）。
  5. 回到 GitHub Desktop → Changes（應該有變更）→ Commit to main → Push origin。
  6. 到 GitHub Actions 檢查最新 Pages workflow 成功，再重新整理網站。網站左上角應顯示 v4.11。
  7. 如需判斷新圖是否更新，請直接開 your-pages-url/taiwan-atlas.html，這是新的獨立頁面。
