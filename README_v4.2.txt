高中一年級｜地科秘笈 v4.2｜圖像先行・完整教懂版

【這一版為什麼重做】
前版最大的問題不是「知識不夠多」，而是仍然太像電子課本：文字很多、圖太少，有些互動做完仍不知道自己應該看懂什麼。v4.2 改成「先看圖 → 找證據 → 動手驗證 → 白話說明 → 正式名詞 → 題型」。

【硬規則】
1. 7章23小節，每一節都有圖像導讀，不再先丟文字牆。
2. 23小節都有自己的專屬互動；目前共55個互動分頁/模式。
3. 真實空間分布優先用正式圖資：USGS、NOAA、中央氣象署、NASA。
4. 看不見的機制才使用本站自製SVG教學圖，例如P/S/表面波、隱沒剖面、空氣上升、月球同步自轉。
5. 每個互動必須回答一個問題；若只是「按了會動」，不列為完成。
6. 官方圖片若因網路或來源暫時無法載入，仍保留本站核心圖解、文字與官方來源連結，不用假資料補空白。
