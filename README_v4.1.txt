高中一年級｜地科秘笈 v4.1（高中教師嚴格審核示範版）

本版不是增加更多按鈕，而是修正「互動很多但未必教懂」的問題。

本輪重點審核：第2章 固體地球、第5章 地球與太空。

教師級原則
1. 先對照高中必修地科課綱核心，再決定網站內容。
2. 真實全球分布、海床年齡、太陽系分類等，需要資料精度的內容優先使用官方圖資／官方頁面。
3. 自製動畫只用來解釋看不見的機制，不用自畫簡圖冒充真實分布圖。
4. 每個互動都必須能回答一個「為什麼」，做完要能說出因果。
5. 每節標出「必會、最容易失分、考題判讀」。
6. 外部官方資源以新分頁開啟；若離線使用，這些外部圖資／頁面需連網。

執行方式
直接開啟 index.html。建議以 Chrome / Edge / Safari 並保持網路連線，以顯示官方外部圖資。
